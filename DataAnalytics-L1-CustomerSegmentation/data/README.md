# Dataset

This project uses the **Online Retail** dataset from the UCI Machine Learning Repository.

- Source: UCI Machine Learning Repository, Dataset 352
- Dataset: Online Retail
- Citation: Chen, D. (2015). *Online Retail*. UCI Machine Learning Repository.
- DOI: 10.24432/C5BW33
- License: CC BY 4.0

The raw `Online Retail.xlsx` file is intentionally not stored in this repository because it is approximately 22.6 MB. The notebook downloads the dataset from UCI automatically using `ucimlrepo`.

If automatic download is unavailable, download the dataset from UCI and place `Online Retail.xlsx` in this `data/` folder.
